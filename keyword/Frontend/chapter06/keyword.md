- query key와 요청 상태

  query key : React Query에서 캐시된 데이터를 식별하는 고유한 키

  역할

    - 캐시 식별자 : 각 쿼리의 결과를 캐시에 저장할 때 사용
    - 의존성 관리 : Query key가 변경되면 자동으로 새로운 데이터를 fetch
    - 캐시 무효화 타겟 : 특정 데이터를 무효화 할 때 Query key로 타겟팅

      무효화 : 캐시를 stale 상태로 마킹하는 것


    query key 설계 원칙
    
    - 계층적 구조
        - 부분적 무효화가 쉽다.
        - 관련된 쿼리를 한 번에 관리 가능
        - 쿼리 간의 관계가 명확
    - 네이밍 일관성
    - 동적 파라미터 마지막에
    
    **요청 상태**
    
    - 쿼리상태 : 데이터에 대한 정보
        - success : 쿼리 성공, 데이터가 쿼리캐시에 설정됨
        - error : 쿼리 실패
        - pending : 쿼리캐시에 데이터가 없음
    - 페치상태 : Fn에 대한 정보(Fn : 함수)
        - fetching : queryFn 요청이 실행중, 데이터 기다리는중
        - paused : queryFn, mutationFn 이 실행중이지 않음(인터넷 연결 안 됨 offline)
            
            mutationFn : 데이터를 바꾸는 요청
            
        - idle : ~Fn 실행중이 아님
    
    쿼리상태와 페치상태는 서로 독립적
    
    - 목록, 검색과 상세에 같은 query key를 쓰면 어떤 문제가 생길까요? 페이지 번호, 검색어와 영화 ID를 포함하는 이유도 함께 생각해 보세요.
        
        React Query가 서로 다른 데이터를 같은 캐시 데이터라고 착각해 데이터가 섞이거나 덮어쓸 수 있다.
        
        목록 화면에서 검색 결과가 보이거나, 상세 화면에서 목록 데이터 형식을 받게될 수 있다.
        
        따라서 페이지 번호는 각 페이지 목록을 따로 캐시하고, 검색어는 검색어별 결과 구분, 영화 ID는 영화별 상세 정보 구분
        
    - `enabled: false`인데도 `isPending`이 참일 수 있는 이유는 무엇이며, 이때 `isLoading`은 어떤 값일까요?
        
        enabled: false는 요청 실행만 막는다 → 데이터가 아직 없으면 Query 상태는 pending일 수 있다.
        
        isLoading → isPending && isFetching

- 캐시 수명과 재조회

  캐시 수명(cacheTime, gcTime) : 데이터가 캐시에 유효한 상태로 남아있을 수 있도록 설정된 시간(캐시 데이터가 메모리에 유지되는 시간)

  요청 후 설정한 시간 동안은 같은 쿼리 호출 시 캐시된 결과를 사용한다.

  staleTime : 데이터가 stale 상태로 간주되는 기간

  stale : 이전 쿼리 결과가 캐시된 후, 그 결과가 일정 시간동안 업데이트 되지 않은 상태

    - `staleTime`과 `gcTime`은 각각 언제부터 계산하며, 시간이 지난 뒤 캐시에 어떤 차이가 생길까요?

      staleTime은 API 요청 성공 후 데이터가 캐시에 저장된 시점부터

      gcTime은 해당 쿼리를 사용하는 화면이 사라진 후부터

      즉, staleTime은 화면에 들어간 순간부터 시작, gcTime 화면에 들어갔나가 나온 후부터 시작(화면에 계속 있으면 시작X)라 볼 수 있다.

    - 전역 기본값과 개별 `useQuery`의 `staleTime`은 어떤 기준으로 정하면 좋을까요?

      전역 기본값: 앱 전체의 모든 useQuery에 자동으로 적용되는 기본 설정

      개별 : 기본값 위에 덮음

      데이터가 얼마나 자주 바뀌고 최신화 되는게 중요할 수록 짧게하고

      자주 바뀌지 않아도 되는 데이터일 수록 길게 설정한다.
