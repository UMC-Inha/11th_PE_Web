# PK, FK란?
* **PK (primary key)**: 테이블에서 각 레코드를 식별하기 위한 컬럼
* **FK (foreign key)**: 한 컬럼이 다른 테이블의 PK를 참조하기 위해 사용하는 key
* PK는 테이블의 고유 식별자 역할, FK는 다른 테이블의 PK를 참조하여 테이블 간의 연결을 만든다.

# ERD란?
* 데이터베이스의 구조와 데이터 간 관계를 시각적으로 표현한 다이어그램

# 연관관계란? 그리고 연관관계를 설정하는 방법은?
* 테이블과 테이블이 서로 연결되는 방식
* **1:1 관계** → 한쪽의 한 데이터가 다른쪽의 한 데이터와 연결
* **1:N 관계** → 한쪽의 한 데이터가 다른쪽의 여러 데이터와 연결
* **N:M 관계** → 양 쪽 모두 여러개의 관계와 연결될 수 있음

# 정규화란?
* 데이터 중복을 최소화하고 데이터 일관성을 유지하기 위해 테이블을 분리하는 과정

# 반 정규화란?
* 데이터 중복을 허용하고 테이블을 통합하여 조인을 줄이는 방법

# DB에서의 상속 관계 표현은 어떻게 하는가?
* 상위 테이블과 하위 테이블을 별도로 만들고, 하위 테이블의 기본키를 상위 테이블의 기본키에 대한 외래키로 설정하여 구현한다.
* 즉 공통 속성은 상위 테이블에, 고유 속성은 하위 테이블에 구현하면 하위 테이블의 PK = 상위 테이블을 참조하는 FK

# 인덱스란?
* 데이터베이스 검색 능력 향상을 위해 특정 컬럼의 값을 별도의 자료구조로 구성하여 데이터의 위치를 빠르게 찾을 수 있도록 하는 객체
* PK는 데이터를 식별하기 위한 키이고 인덱스는 빠르게 검색하기 위한 자료구조로 서로 다름. 보통 PK가 인덱스를 자동으로 생성하거나 인덱스와 결합된 방식으로 관리
* 인덱스를 위한 별도의 저장공간 필요
