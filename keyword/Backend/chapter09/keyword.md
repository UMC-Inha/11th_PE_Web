- Swagger / OpenAPI

  OpenAPI : REST API의 구조와 사용법을 표현하는 표준 명세

    - API 디자인 : Swagger-editor를 통해 api를 문서화하고 빠르게 명세
    - API Development : Swagger-codegen을 통해 작성된 문서를 통해 SDK를 생성하여 빌드 프로세스를 간소화
    - API Documnetation : Swagger-ui를 통해 작성된 API를 시각화
    - API Testing : Swagger-Insepctor를 통해 API를 시각화하고 빠른 테스팅을 진행
    - Standardize : Swagger-hub를 통해 개인, 팀원들이 API 정보를 공유하는 Hub

  Swagger : OpenAPI 명세를 사람이 편하게 확인하고 직접 실행할 수 있게 도와주는 도구

  Swagger 장점

    - API 사용 방법을 별도의 문서 없이 확인 가능
    - 프론트엔드 개발자가 요청 URL과 데이터 형식을 쉽게 확인 가능
    - API별 성공 및 실패 응답을 명확하게 공유
    - Swagger UI에서 API를 직접 호출하여 빠르게 테스트
    - 인증이 필요한 API와 공개 API를 구분
    - API 명세를 기준으로 팀원 간 의사소통 오류 감소
- 단위 테스트

  단위 테스트 : 클래스나 메서드처럼 작은 코드 단위를 독립적으로 검사하는 테스트

  외부 DB나 실제 서버를 사용하지 않고, Repository 같은 의존 객체를 가짜 객체로 교체

  실행 속도가 빠르다

  실패 원인을 찾기 쉽다

  외부 시스템의 상태에 영향을 적게 받는다.

  특정 예외 상황을 쉽게 만들 수 있다.

  하나의 클래스나 메서드가 의도대로 동작하는지 확인하는 데 적합하다.

- 통합 테스트

  통합 테스트 : Controller, Service, Repository, DB 등 여러 계층이 연결된 상태에서 전체 흐름을 검사하는 테스트

  단위 테스트보다 범위가 넓다

  실제 사용 환경과 비슷하지만, 실행 시간이 더 길고 실패 원인을 찾는 과정이 복잡할 수 있다.

  @SpringBootTest: 실제 애플리케이션과 유사하게 Spring Bean을 모두 생성

  @AutoConfigureMockMvc: 실제 서버 포트를 열지 않고 HTTP 요청을 테스트

  @Transactional: 테스트가 끝난 뒤 테스트에서 변경한 DB 데이터를 되돌린다.

  MockMvc: 가상의 HTTP 요청을 보내고 응답을 검증

- Mock, Stub

  테스트에서 실제 의존 객체를 대신하는 테스트 대역

  Mock : 호출 여부와 호출 방법까지 검증할 수 있는 가짜 객체 → 호출 여부와 상호작용 검증

  verify()

  저장이 호출되지 않았는지 검증

  Stub : 테스트에 필요한 값을 미리 반환하도록 만든 객체 → 값을 반환하여 테스트 상황 준비

  given().willReturn()

  중복 데이터가 있다고 반환

- given-when-then

  테스트 코드를 준비, 실행, 검증의 세 단계로 나누는 작성 방식

  Given

  테스트에 필요한 상황과 데이터를 준비

  ex) 이미 같은 영화에 평점을 작성했다.

  When

  검사하려는 기능을 실행

  ex) 같은 영화에 평점을 다시 등록했다.

  Then

  실행 결과가 예상과 같은지 검증

  ex) 409와 RATING409_1 예외가 발생한다.

  테스트의 의도가 명확하게 드러난다

  테스트 코드의 준비와 실행, 검증 부분이 구분

  실패한 테스트에서 어떤 상황을 검사했는지 이해하기 쉽다

  다른 개발자가 테스트 코드를 읽기 쉽다

  테스트 이름을 작성하기 쉽다.

- 회귀 테스트

  기존에 정상 동작하던 기능이 코드 변경 이후 다시 고장 나지 않았는지 확인하는 테스트

  기존 버그가 다시 발생하는 것을 방지

  새로운 코드가 기존 기능을 망가뜨리는지 확인할

  리팩터링 이후에도 기존 동작이 유지되는지 확인

  사람이 모든 기능을 직접 확인하지 않아도 된다.

  CI/CD 과정에서 변경된 코드를 자동으로 검증
