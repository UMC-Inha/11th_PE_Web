3주차의 Raw SQL 방식에서는 SQL문을 직접 작성하고, JdbcTemplate을 이용해 데이터를 조회하거나 저장

JPA 방식으로 변경하면서 SQL을 직접 작성하는 대신 JpaRepository와 엔티티를 통해 데이터베이스에 접근하도록 바꿈

또한 조회 결과를 Map<String, Object> 형태로 직접 다루던 방식에서 엔티티와 DTO를 활용하는 구조로 변경되어 코드의 가독성과 유지보수성 향상

연관된 데이터도 외래 키 값을 직접 다루기보다 @ManyToOne과 같은 연관관계 매핑을 통해 객체 형태로 다룰 수 있게 됨
